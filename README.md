### Descrição do Projeto

Sistema web desenvolvido para a disciplina de Programação Web, com foco na criação de um site corporativo para a empresa **Águas Claras Manutenção de Piscinas**.

A aplicação permite apresentar a empresa, divulgar serviços e receber solicitações de orçamento com coleta estruturada de dados dos clientes.

### Funcionalidades

* Página institucional da empresa;
* Página de exibição de serviços;
* Página de Formulário de solicitação de orçamento;
* Coleta de dados do cliente e da piscina;
* Integração com API de CEP.

### Conclusão

O projeto cumpre o objetivo de criar um site corporativo simples, funcional e com integração externa, aplicando conceitos básicos de desenvolvimento web. Atende:
● Página Inicial: Apresentação geral do negócio.
● Página de Produtos ou Serviços: Detalhamento do portfólio oferecido.
● Página Institucional: Informações sobre a empresa, equipe ou estrutura.
● Página de Conversão: Seção contendo formulário (ex: contato, matrícula, agendamento ou reserva).
● Interface e Responsividade: Uso estrito de HTML semântico e CSSexterno. O layout deve adaptar-se a dispositivos móveis utilizando Media Queries, Flexbox e/ou CSS Grid.
● Interatividade (JavaScript): Implementação de funcionalidades interativas via manipulação do DOM (ex: filtros, menus, cálculos) e validação dos campos obrigatórios no formulário.
● Consumo de API Externa: Uso obrigatório da Fetch API para buscar dados em formato JSON de uma API pública (ex: ViaCEP para endereços, publicapis para cotações/clima) e renderizar essa resposta dinamicamente na tela.
● Hospedagem: O projeto final deve estar publicado e acessível online
(GitHub Pages).
